# Archived architecture records

This directory preserves superseded architecture and implementation-plan records verbatim.

They are retained for decision history and possible future reuse. They are **not current implementation instructions**. Current application behaviour is defined by `docs/SPEC.md`; current architecture is defined by `docs/TARGET_ARCHITECTURE.md`; future work remains in `ROADMAP.md`.

The 2026-09-28 re-baseline moved the detailed v0.5 Cloudflare/database programme records here after the development repository became public, GitHub Pages was restored for development, the development Cloudflare Worker was deleted, and the two-repository Pages model was deliberately retained.
